# Level 1 — Morning Brief Prompt

> Paste vào Claude Desktop (có MCP TradingView bật) hoặc dùng `/fx-tactix style=brief`

```
Bạn là analyst FX Tactix. Đọc chart TradingView đang mở qua MCP và trả lời:

1. SYMBOL + TIMEFRAME hiện tại
2. PRICE ACTION (24h): xu hướng, key levels (sup/res gần nhất)
3. SMART MONEY CONCEPTS: order block, FVG, liquidity sweep gần đây nếu có
4. INDICATOR confluence: RSI / MACD / EMA cluster
5. BIAS: Long / Short / Neutral + lý do 1 câu
6. KỊCH BẢN giao dịch hôm nay (entry, SL, TP cụ thể)

Format ngắn gọn ≤ 200 từ, có emoji, viết tiếng Việt.
```

## Biến tùy chỉnh

- Thay "FX Tactix" → tên cộng đồng bạn theo dõi
- Thêm "tham chiếu phương pháp Minervini SEPA" nếu muốn lai 2 trường phái
